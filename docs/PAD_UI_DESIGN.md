# SpektraLab Pad 界面设计规格（v1）

日期：2026-11-11  
适用：vivo Pad6 Pro（2512×3840 px，480 dpi，横屏 **1280×837 dp**）  
设计稿：`docs/design/pad-landscape-main.png`、`pad-portrait.png`、`pad-states.png`  
生成脚本：`tools/design/render_mockups.py`（尺寸用 1.25 px/dp，按真实 dp 换算）

> 说明：设计稿中的照片、胶片名与数值是演示内容；胶片/相纸的真实清单以 App 资源为准
> （25 款胶片 + 9 款相纸，共 34 个 profile）。设计稿只表达布局、层级与交互，不代表现有代码已实现。

---

## 1. 目标与约束

### 1.1 目标

1. 把现在"底部页签 + 弹出面板"的手机式布局，换成**平板横屏三栏工作台**：左选胶片、中看照片、右调参数。
2. 常用参数**常驻可见**，减少弹层遮挡照片；一次调整能立刻看到画面变化。
3. 让后续跟随上游版本的成本可控：UI 改动集中在少数方法，引擎调用与 JNI 接口一律不动。

### 1.2 硬约束（不能违反）

| 约束 | 原因 |
|---|---|
| 不改引擎、不改 JNI 方法名与包名 `app.spektralab.engine` | 引擎是官方二进制，JNI 按类名绑定 |
| 不新增需要引擎支持的功能 | 公开源码不完整，无法自行扩展引擎 |
| 保留现有全部能力：34 款胶片/相纸、三档导出、RAW、构图、边框 | 这些是产品本体，不能因为改版丢弃 |
| 界面用 Java 代码构建（本工程无 XML layout） | 现有实现即如此，见 `MainActivity.java` |
| 所有可点区域 ≥48dp | 手指与隔空操作都更稳 |

### 1.3 现有界面的问题（改造理由）

- 底部 6 个页签 + 弹出面板，选中胶片后要反复开合，照片频繁被遮住；
- 参数调节是"一页一组"的抽屉结构，调颗粒就要离开当前页；
- 横屏时左右两侧大量空白，照片没有获得应得的面积；
- 主操作（导出）藏在右上角图标里，不够显眼。

## 2. 设计概念："暗房工作台"

**一句话**：一块深蓝工作台上摊着照片，左手边是胶片盒，右手边是放大机的旋钮。

- **深蓝画布** `#11164B`：沿用现有工作台底色，让照片成为唯一亮部；
- **纸白面板** `#F4F2EC`：沿用现有卡片色，像相纸/暗房记录纸；
- **墨黑文字** `#171717`：高对比、不刺眼；
- **暖棕强调** `#B49B7A`：滑杆与数值，取自参考稿，和深蓝形成冷暖对比；
- **品牌色只用于胶片卡**：CineStill 红、Kodak 黄、Fuji 绿、Ilford 灰——一眼分辨，不污染功能区。

为什么是三栏而不是"抽屉 + 全屏"：

1. 1280dp 宽足够容纳 252 + 画布 + 300，画布仍剩 ~640dp；
2. 参数常驻，调参时照片始终可见，符合"所见即所得"；
3. 左栏与右栏都可折叠，需要大图时一键让位给照片。

## 3. 布局与栅格

### 3.1 横屏（≥1000dp）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 64dp：logo｜SpektraLab Pad｜版本        ↶ ↷ 导出 ⋯        │
├──────────┬──────────────────────────────────┬────────────────┤
│ 左栏      │ 画布（自适应，圆角 14）            │ 右栏 300dp      │
│ 252dp    │  · 文件信息（顶部居中，弱化）      │ 调整：4 个滑杆   │
│ 胶片/相纸 │  · 胶片/相纸胶囊（左上）           │ 冲印 ▸          │
│ 2 列卡片  │  · 缩放 %（左下）                 │ 尺度 ▸          │
│          │  · 按住看原图（右下）              │ 构图 ▸          │
│ 全部 34 款│  · 双指缩放/拖动提示（底部居中）   │ 边框 ▸          │
│          │                                  │ [导出 JPEG]     │
├──────────┴──────────────────────────────────┴────────────────┤
│ 状态栏 44dp：尺寸/MP ｜ 渲染耗时 ｜ 设备上限                   │
└──────────────────────────────────────────────────────────────┘
```

| 元素 | 数值 |
|---|---|
| 外边距 | 20dp（四边） |
| 栏间距 | 20dp |
| 顶栏高 | 64dp |
| 状态栏高 | 44dp（含 6dp 上边线） |
| 左栏宽 | 252dp（2 列，列距 12dp，卡宽 120dp） |
| 右栏宽 | 300dp |
| 画布 | 剩余宽度，高 = 屏高 − 顶栏 − 状态栏 − 上下边距（≈709dp） |
| 画布圆角 | 14dp |
| 照片圆角 | 10dp，内缩 12dp 起，等比适配（fit） |
| 卡片圆角 | 10dp，选中外扩 3dp + 2dp 深蓝描边 |

### 3.2 竖屏（<840dp）

- 单栏：顶栏 → 画布（等比，宽度占满）→ 调整（3 个主滑杆 + 2 行设置）→ 底部抽屉（胶片与相纸横向滚动，卡 118×70dp）。
- 抽屉可上拉半屏，显示完整列表；下拉收起，只留把手。

### 3.3 中间宽度（840–999dp）

- 两栏：左栏折叠为 72dp 图标条（胶片/相纸/工艺三个入口），右栏 280dp 抽屉式。
- 画布获得最大宽度。

### 3.4 断点规则

| 宽度 | 布局 |
|---|---|
| ≥1000dp | 三栏常驻（默认） |
| 840–999dp | 两栏：左栏图标条 + 右栏可收抽屉 |
| <840dp | 单栏 + 底部抽屉（竖屏） |

## 4. 组件规格

### 4.1 顶栏（64dp）

| 区块 | 规格 |
|---|---|
| 左：logo | 20dp 圆环（2dp 描边）+ 8dp 实心点，距左 20dp |
| 标题 | 17sp / 墨黑 / 常规字重；与 logo 间距 10dp |
| 版本 | 9sp / 灰 `#96928A`，标题后 8dp，只在宽屏显示 |
| 右：撤销 / 重做 | 24dp 图标，间距 36dp，距导出 40dp |
| 导出 | 24dp 下载图标；按下 56dp 圆底反馈 |
| 更多 | 24dp 三点；打开菜单（反馈群、更新检查、关于） |
| 分割线 | 1dp `#E0DCD3` |

状态：撤销/重做在无历史时降到 30% 不透明度且不响应点击；导出在无照片时禁用。

### 4.2 左栏：胶片与相纸

- 标题 15sp；下方 32dp 分段控件（底 `#E8E4DB`，选中白底 6dp 圆角，文字 12sp）。
- 卡片：缩略图 120×84dp（圆角 10），下方名称 12sp、类型 10sp 灰。
- 缩略图内容：品牌名 8sp 白字（左上）+ ISO 8sp 白字（左下）+ 斜向色带，代表该胶片的色彩倾向；**不加载真实样片**，避免首屏等待。
- 选中态：`#1C2AA5` 2dp 描边、外扩 3dp、名称转深蓝加粗。
- 交互：
  - 单击 = 选中并渲染（防抖 150ms）；
  - 长按 400ms = 弹出该胶片简介（品牌、类型、推荐场景）与"设为默认"；
  - 双击 = 选中并强制全尺寸渲染（等同长按导入的"按原始尺寸"）。
- 底部计数行"全部 34 款胶片 / 相纸"，点击进入完整列表（全屏网格，可搜索）。
- 相纸分段：同样的卡片形式，9 款；选中后立即重算印相。

### 4.3 右栏：调整与工艺

**A. 主滑杆（4 条，常驻）**

| 项 | 标签 | 数值格式 | 默认 |
|---|---|---|---|
| 曝光 | 曝光 | 带符号一位小数，如 `+0.3` | 0.0 |
| 颗粒 | 颗粒 | 整数 0–100 | 36 |
| 光晕 | 光晕 | 整数 0–100 | 28 |
| 眩光 | 眩光 | 整数 0–100 | 12 |

- 行高 58dp：标签 13sp 左、数值 13sp 右（等宽数字）；
- 轨道 4dp `#DDD8CF`，已选段 4dp `#B49B7A`，滑钮 18dp 白底 + 1dp 灰边 + 6dp 暖棕芯；
- 命中区：整行 44dp 高都可拖动（手指不必压在细轨道上）；
- 单击轨道跳转；双击滑钮复位该项；长按数值输入精确值；
- 拖动中**不**弹键盘、不刷新整页，只更新画面与数值。

**B. 工艺分组（4 行手风琴）**

| 行 | 右侧摘要 | 展开内容（沿用现有控件） |
|---|---|---|
| 冲印 | `Endura Premier` | 相纸列表 + 配光（自动曝光）+ 印相强度 |
| 尺度 | `135 / 36×24 mm` | 画幅九档（135/半格/XPan/645/6×6/6×7/6×9/6×12/6×17） |
| 构图 | `未裁切` | 裁剪比例、旋转、翻转、复位 |
| 边框 | `关闭` | 片边样式、日期后背、颜色 |

- 行高 40dp，标题 13sp，摘要 11sp 灰，右侧 16dp 箭头；
- 展开时箭头旋转 90°，内容内联展开（不弹窗），同时**只展开一组**；
- 展开内容高度不固定，右栏整体可滚动。

**C. 主按钮**

- 高 48dp，圆角 10，底 `#1C2AA5`，文字"导出 JPEG" 14sp 白；
- 下方 10sp 灰字"长边 3400 / 全尺寸可用"；
- 点击进入导出面板（三档：2048 / 3400 / 全尺寸，含预计耗时与体积）。

### 4.4 画布

- 底色：深蓝渐变（中心 `#181E5C` → 边缘 `#11164B`），圆角 14dp；
- 照片：等比 fit，圆角 10dp，1dp 描边 `#5A6296`；
- 浮层（都在照片内，距边 12dp）：
  - 左上：`CineStill 800T / Endura` 胶囊（黑 60%，10sp 白）；
  - 左下：`100%` 胶囊（黑 60%，10sp 白）；
  - 右下：`按住看原图`（白底黑字，10sp，圆角 11dp）；
- 画布顶部居中（照片外）：文件名与像素尺寸，9sp `#BCC2E2`；
- 画布底部居中（照片外）：`双指缩放 / 拖动移动` 9sp `#969EC4`，首次使用 5 秒后淡出；
- 手势：
  - 单指拖动 = 平移（放大状态）；双指捏合 = 50%–400%；
  - 双击 = 100% ↔ 适应窗口；
  - 长按照片 = 显示原图（松手恢复），与右下胶囊等价；
  - 三指点击 = 切换"仅看照片"（左右栏收起）。

### 4.5 状态栏（44dp）

左：`4700 x 3133 / 15.9 MP`；中：`渲染 1.2 s / 缓存命中`；右：`本机上限 16.5 MP / 全尺寸可用`。
字号 10sp，灰 `#706D66`，等宽数字。渲染中时中间变为进度条（宽 160dp）。

### 4.6 空态（见 `pad-states.png`）

- 居中虚线框（2dp，`#C6C1B7`），内"＋ 导入照片" 14sp、副文案"JPEG / RAW 或从相册选择" 9sp；
- 下方"最近：DSC_2841.JPG"可点；
- 空态时右栏与状态栏隐藏，只留顶栏与左栏（胶片预览仍然可看）。

### 4.7 渲染中 / 导出完成

- 渲染中：照片上方覆盖 2dp 细进度条 + "正在渲染 / 62%"；**旧图保持可见**，不闪白；
- 三步状态点：取负片 → 印相 → 打包，完成变绿；
- 导出完成：绿色对勾 + 文件名 + 体积 + 保存路径 + "打开 / 继续调整"。

## 6. 状态与反馈

| 状态 | 触发 | 界面表现 | 可操作 |
|---|---|---|---|
| 空 | 首次启动/清空 | 虚线导入框 + 最近文件 | 导入、看胶片 |
| 载入中 | 选中照片后 | 画布显示缩略图 + 顶部细进度 | 取消 |
| 首帧渲染 | 引擎返回 | 缩略图占位 + "正在渲染" | 调参排队 |
| 就绪 | 渲染完成 | 照片 + 参数 + 状态栏 | 全部 |
| 变更中 | 拖滑杆/换胶片 | 旧图保持 + 细进度 + 数值实时 | 继续调（防抖 150ms） |
| 失败 | 引擎错误码 | 顶部红色条：`E-1001 超出本机内存上限` + "降低尺寸重试" | 重试/换档 |
| 导出中 | 点导出档位 | 进度 + 预计剩余 | 取消 |
| 导出完成 | 写盘成功 | 绿色对勾卡片 | 打开/继续 |
| 离线 | 更新检查失败 | 静默，不打扰 | — |

错误文案统一格式：`E-xxxx 人话解释` + 一个明确动作（降低尺寸 / 换档 / 重试）。现有错误码体系（1001 缓冲超限、1101–1106 RAW、1201–1202 渲染、1301–1303 请求）继续沿用，不新造。

## 7. 交互细节

1. **参数防抖**：拖动停止 150ms 后发起渲染；渲染中再次改动则取消旧请求、只保留最后一次。
2. **对比**：按住"看原图"或长按照片 = 显示原图；松手 120ms 后恢复。对比期间禁用手势，避免误触。
3. **撤销/重做**：只记录参数与预设选择（栈深 20），不记录导入/导出；顶栏图标 + `Ctrl+Z`/`Ctrl+Shift+Z`。
4. **键盘鼠标**（scrcpy / 外接键鼠）：`+`/`-` 缩放、`0` 适应窗口、`1` 100%、空格按住对比、`Ctrl+E` 导出、`Esc` 关闭面板。
5. **滚动**：左栏与右栏独立滚动；画布不参与滚动，避免误滑。
6. **折叠**：两栏顶部各有一个 24dp 收起按钮；折叠后留 48dp 竖条，点按恢复；三指点击同时折叠两栏。
7. **首次使用**：进入后 1 次轻提示"左选胶片，右调参数，长按照片看原图"，3 秒后淡出，不再重复。

## 11. 风险与取舍

1. **单文件 14,633 行**：直接大改会难以合并。策略：先抽出 `PadTheme`（颜色/尺寸常量）与 `PadLayout`（三栏骨架）两个新类，`MainActivity` 只保留调用点，改动面从"整文件"缩到"几十处"。
2. **旋钮改滑杆**：现有光学页是旋钮（支持粗调/细调），改滑杆会损失一点精度。折中：滑杆 + 长按输入精确值；若上游旋钮逻辑复杂，P0 先原样搬入，P2 再换。
3. **渲染性能**：拖动滑杆时若每帧都渲染会卡。必须防抖 + 取消旧任务；大图时先降分辨率预览，松手后全尺寸。
4. **上游更新**：作者若重构 `MainActivity`，我们的补丁可能冲突。应对：改动集中在少数方法、每处加 `// PAD-UI` 标记、保留独立分支与变更日志。
5. **许可**：本变体自用；对外分发需先补齐引擎源码并遵守 GPL/CC BY-SA 与品牌要求。
